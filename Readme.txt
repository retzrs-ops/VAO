======================================================================
  V A O    (VAO – Voice Auto Optimizer)
  Version: 0.4.0
======================================================================

[ 概要 ]
「VAO」は、OBS Studio 用の音声フィルタです。
画面に出る文章を読むだけで、マイクの音量・雑音・声の聞きやすさを自動で整えます。
音量が小さくて聞き取ってもらえない、雑音が気になる、声がこもる、といった
配信のお悩みを、むずかしい設定なしで解決することを目指しています。
OBS の「音声フィルタ」の一覧に「VAO Voice」として追加されます。


[ 作った理由と、設計の考え方 ]
VAO がなぜこのような作りになっているのかを、先にご説明します。

1. いちばんの目的は「音が小さくて聞いてもらえない配信をなくす」ことです。
   視聴者は、音が小さい・雑音が多い・聞き取りにくい配信から、すぐに離れてしまいます。
   映像がどんなに良くても、声が届かなければ見てもらえません。
   そのため VAO は、まず声の音量を適切な大きさにそろえることを最優先にしています。

2. 専門知識がなくても使えるようにしました。
   ふつうは、マイクの音量・ノイズゲート・EQ・コンプレッサーなどを自分で調整します。
   これは初心者にとって、とても大変です。
   VAO は、表示された文章を読むだけで、あなたの声と部屋に合わせて自動で設定します。
   測るのは、部屋の雑音・キーボードとマウスの音・普段の声・大きな声の 5 つです。

3. OBS だけで完結します。
   他のソフト（VST3 プラグインを動かすための別のソフト）を用意する必要はありません。
   OBS の中で動くので、配線も増えません。
   また、起動のたびに更新を知らせる通知を出したり、勝手に通信したりしません。
   音声データを外に送ることもありません（すべてお使いのパソコンの中で処理します）。

4. 処理の順番には理由があります。VAO は、次の順に音を整えます。

     入力ゲイン → ハイパス → AI ノイズ抑制 → ノイズゲート → EQ → コンプレッサー
              → ディエッサー → 出力ゲイン → リミッター

   ・最初に「入力ゲイン」で、声の大きさをそろえます。AI ノイズ抑制やノイズゲートなどは、ほどよい大きさの声を
     前提に動くので、声が小さいままだと、声まで雑音と間違えて削ってしまうことがあるからです
     （音響の専門家の助言を取り入れました）。後ろの処理が、人によらず同じ条件で動くようにする効果もあります。
     ただし、デジタルのゲインは声と雑音を同じだけ大きくするので、雑音の割合そのものは良くなりません。
     声がとても小さいときは、先に Windows のマイク音量（オーディオインターフェースのゲイン）を上げてください。
   ・低い雑音は、そのあとで取り除きます。あとの処理が雑音に引きずられないようにするためです。
   ・雑音を先に減らしてから、音色（EQ）と音量（コンプ・ゲイン）を整えます。
     先に音量を上げると、雑音まで一緒に大きくなってしまうからです。
   ・「サ行」の刺さりは、音量を上げる前に抑えます。大きくしたあとでは耳に痛くなるためです。
   ・リミッターは、必ず最後です。どれだけ大きくしても、叫び声や笑い声で音が割れないよう、
     最後に上限を決めて守ります。

5. 入力の時点で音割れしている音は、あとからは直せません。
   マイク側の音量が大きすぎると、声がすでに割れた状態で届きます。
   これは VAO では直せないので、測定中に見つけたら
   「マイク側の音量を下げてください」とお知らせします。

6. EQ には「味付け」があります。
   声のこもりや抜けの悪さは、測定から自動で補正します。
   そのうえで、好みの音色（クリア・あたたかい・ラジオ・やわらか・ハキハキ）を
   プリセットから選べるようにしました。

7. 設定は 1 画面で、一覧できるようにしました。
   各処理は見出しのチェックでオン・オフでき、数値は後から自由に直せます。
   自動設定は「すべて自動設定」ボタン 1 つだけです。迷わないようにしています。

8. 無料で、ソースコードも公開しています（GPL）。


[ 主な機能 ]
・すべて自動設定      : 約 26 秒の測定をして、下のすべての処理の設定値を自動で決めます
・入力ゲイン          : 最初に声の大きさをそろえて、後ろの処理が正しく動くようにします
・ハイパス            : エアコンや机の振動などの、低い雑音をカットします
・AI ノイズ抑制       : ファン・空調・ヒスノイズなど、常に鳴っている雑音を減らします（RNNoise を内蔵）
・ノイズゲート        : 声がないときの「サーッ」「カチカチ」を静かにします
・EQ（音色）          : こもりを取り、声をはっきりさせます。味付けのプリセットが 6 種類あります
・コンプレッサー      : 声の大小のばらつきをそろえます
・ディエッサー        : 「さしすせそ」の刺さりを抑えます
・出力ゲイン          : 全体の音量を、聞きやすい大きさに上げ下げします
・リミッター          : 音割れしないよう、音量の上限を決めます
・オン・オフ          : 各処理は、見出しのチェックで個別にオン・オフできます


[ 動作環境 ]
・OS: Windows 10 / 11 (64bit)
・OBS Studio（動作確認: 32.2.2）
・OBS の音声設定のサンプルレートが 48 kHz であること（AI ノイズ抑制は 48 kHz のときだけ動きます。
  OBS の既定は 48 kHz です。それ以外でも、ほかの処理は動きます）
・インターネット接続は不要です
・管理者権限は不要です


[ 同梱ファイル ]
インストーラーで入れると、次の場所に置かれます。
  C:\ProgramData\obs-studio\plugins\VAO\
    bin\64bit\VAO.dll        : 本体
    data\locale\             : 画面の文字（日本語・英語）
    licenses\                : 使っているソフトのライセンス文
    Readme.txt               : このファイル
    LICENSE                  : VAO のライセンス（GPL-2.0）
    unins000.exe             : アンインストール用
  ※ これらのファイルは、削除・移動しないでください。

■ インストール方法
----------------------------------------------------------------------

【 かんたんな方法（おすすめ）: インストーラー 】
  1. OBS Studio を終了します（起動中だとインストールできません）。
  2. ダウンロードした「VAO-0.2.0-windows-x64-Setup.exe」をダブルクリックします。
     ※ 青い画面で「WindowsによってPCが保護されました」と出ることがあります。
        ソフトに電子署名が付いていないためで、VAO 自体に問題はありません。
        「詳細情報」を押し、出てくる「実行」を押してください。
  3. 最初の画面で「インストール」を押します（言語の選択画面が出たら、「日本語」のまま「OK」を押します）。
     終わったら「完了」を押します。
     入れ先を選ぶ画面はありません（間違えないよう、決まった場所に入れます）。
  4. 最後の画面に、使い始める手順が出ます。

  ・OBS Studio が見つからないときは、「先に OBS Studio をインストールしてください」と表示します。
  ・OBS が起動中のときは、「OBS を終了してから『再試行』を押してください」と表示します。

【 更新するとき 】
  新しいインストーラーを、もう一度実行してください。そのまま上書きされます。
  フィルタの設定（OBS のシーンに保存されたもの）は消えません。

【 削除するとき 】
  Windows の「設定」→「アプリ」→「インストールされているアプリ」で「VAO」を選び、
  「アンインストール」を押します。

【 zip で入れる方法（上級者向け） 】
  zip を解凍すると、中に「VAO」フォルダがあります。
  そのフォルダごと、次の場所へコピーしてください（フォルダの階層を変えないでください）。
    C:\ProgramData\obs-studio\plugins\
  → 結果として「C:\ProgramData\obs-studio\plugins\VAO\bin\64bit\VAO.dll」の形になれば OK です。
  ※ OBS が読み込むのは、この ProgramData のフォルダです。「%APPDATA%」側（ユーザーフォルダ）に
     入れても、OBS は読み込みません。
  ※ インストーラーと zip の両方で入れると、VAO が 2 つ見つかって動かなくなります。
     どちらか一方だけにしてください。

■ 使い方
----------------------------------------------------------------------

1. OBS Studio を起動し、マイクの音声ソース（「音声入力キャプチャ」など）を右クリックして
   「フィルタ」を開きます。
2. 左下の「＋」から「VAO Voice」を選んで追加します。
   フィルタ名の左にある「目」のアイコンがオンになっていることを確認してください
   （オフだと、音がフィルタに届かず、測定が始まりません）。
3. 「すべて自動設定（測定する）」ボタンを押します。
4. 画面の案内（「状態」の欄）に従います。合計で約 26 秒です。
     ① あと 3 秒、黙っている          （部屋の雑音を測ります）
     ② あと 4 秒、キーボードを叩く     （いつものように。打鍵音を測ります）
     ③ あと 3 秒、マウスをクリックする  （カチカチ押します。クリック音を測ります）
     ④ あと 12 秒、画面の文章を読む    （普段の声で。声の大きさと音色を測ります）
     ⑤ あと 4 秒、一番大きい声で「あー」（笑い声や叫び声のつもりで）
5. 「完了。設定しました。」と出たら終わりです。すべての処理が自動で設定され、オンになります。
6. 試しに話して、OBS の音量メーターと聞こえ方を確認してください。
   設定は OBS に保存されるので、毎回やり直す必要はありません。
   マイクや部屋を変えたときは、もう一度「すべて自動設定」を押してください。

【 読む文章（日本語版の例） 】
  さあ、配信を始めます。ピカピカの新しいマイクで、静かな部屋から、すてきな時間を
  お届けします。ポップコーンの準備はいいですか？
  （サ行・パ行・いろいろな母音が入っていて、1 回読むだけで声の特徴が測れる文章です）

【 うまく測るコツ 】
  ・① のときは、本当に静かにしてください（呼吸は大丈夫です）。
  ・② ③ は、ふだん配信中に出る音を、そのまま出してください。
  ・④ は、配信中と同じマイクの距離・同じ声の大きさで読んでください。
  ・⑤ は、配信中に出るいちばん大きい声を、少し大げさに出してください。
  ・測定中は、ゲームの音や BGM を止めてください（マイクに入ると、正しく測れません）。

【 数値を自分で直したいとき 】
  すべてのスライダーは、自動設定のあとでも自由に動かせます。
  「すべて自動設定」を押すと、またすべて自動で決め直されます。


----------------------------------------------------------------------
■ 設定項目リファレンス（ヘルプ）
----------------------------------------------------------------------

【 画面の構成 】
  上から、「状態」（案内の表示）・「すべて自動設定（測定する）」ボタン、
  そのあとに処理の順番どおりに 7 つの項目が並びます。
  各項目の見出しのチェックで、その処理をオン・オフできます。

・状態
   測定の案内や、結果（完了・警告）が出ます。

・入力ゲイン（最初に声の大きさをそろえる）
   ゲイン        : 最初にかける音量です（-20〜+40 dB）。
   自動設定では、声の平均が -20 dB 付近になるように決まります（声が小さい人ほど大きく上がります）。
   「出力ゲイン」とは別で、こちらは処理の前、出力ゲインは処理のあと（最後の仕上げ）の音量です。

・ハイパス（低い雑音をカット）
   カットする周波数: これより低い音を切ります（40〜200 Hz、自動設定では 80 Hz）。
   上げすぎると声が細くなります。低い男性の声で細く感じたら、下げてください。

・AI ノイズ抑制（ファン・空調・ささやき雑音）
   強さ: 0〜100 %。大きいほど、雑音を強く消します。
   自動設定では、部屋の雑音が大きいほど強くなります（キーボードやマウスの音が出る環境では 100 %）。
   強くしすぎると、声が少し不自然になることがあります。
   ※ 48 kHz のときだけ動きます。音が約 10 ミリ秒遅れます。

・ノイズゲート（無音時の雑音を消す）
   しきい値: これより小さい音を、声がないものとして静かにします（-80〜-20 dB）。
   自動設定では、部屋の雑音とキーボード・マウスの音より少し上に置きます。
   声の出だしや語尾が切れるときは、数字を下げてください（左へ動かす）。
   雑音が残るときは、数字を上げてください（右へ動かす）。

・EQ（声の音色）
   味付け: ナチュラル / クリア（くっきり）/ あたたかい / ラジオ（太く前へ）/
           やわらか / ハキハキ（元気）
   「味付け」を選ぶと、下の 4 つのスライダーが、その音色の値になります。
   「すべて自動設定」では、測定した声のバランス（こもり・抜け）に合わせた補正に、
   選んでいる味付けを足します。
   低域（厚み）  : 100 Hz 付近。上げると声に厚みが出ます。
   こもり        : 300 Hz 付近。下げると、こもった感じが取れます。
   明瞭さ        : 3 kHz 付近。上げると、言葉がはっきり聞こえます。
   空気感        : 8 kHz 以上。上げると、明るく、抜けがよくなります。
   範囲はそれぞれ -12〜+12 dB です。

・コンプレッサー（声のばらつきをそろえる）
   しきい値      : これより大きい音を、抑えはじめる位置です（-60〜0 dB）。
   比率          : 抑える強さです（1〜10）。大きいほど、強く抑えます。
   小さい声と大きい声の差を縮めるので、全体の音量を上げやすくなります。

・ディエッサー（サ行の刺さりを抑える）
   しきい値      : これより強いサ行の音を抑えます（-70〜-10 dB）。
   サ行が耳に痛いときは数字を下げます。声がこもるときは数字を上げます。

・目標の音量（「すべて自動設定」ボタンの真下）
   目標の音量    : 仕上がりの声の大きさの目標です（-18〜-14 LUFS、1 dB 刻み。標準は -18）。
                   -18 は雑談配信向け、-14 はゲーム配信向けの目安です。数字が大きい（0 に近い）ほど、大きな音です。
                   LUFS は、人の耳で感じる音の大きさを表す単位です。ゲームの音と一緒に流す配信で、声をもっと
                   前に出したいときは、-16 や -14 にしてください。
                   「すべて自動設定」はこの目標で出力ゲインを決めます。
                   自動設定のあとでスライダーを動かすと、動かし終わって少したったあと（約 0.5 秒）、
                   出力ゲインがその目標に合わせて、自動で変わります。測定は、やり直さなくて大丈夫です。
                   測定の結果は保存されるので、OBS を再起動したあとでも、動かして合わせ直せます。
   ※ 音割れを防ぐため、目標の音量まで上げられないことがあります。そのときは、状態欄にお知らせが出ます。
   いちばん触る設定なので、「すべて自動設定」ボタンのすぐ下に置いてあります。

・出力ゲイン（音量）
   ゲイン        : 全体の音量です（-20〜+40 dB）。目標の音量から自動で決まりますが、手で変えることもできます。
   音量が小さい配信の多くは、ここが大きく上がります。

・リミッター（音割れ防止）
   上限          : これ以上は絶対に大きくしない音量です（-12〜0 dB、自動設定では -3.0 dB）。
   常にオンにしておくことをおすすめします。
   ※ 音が約 2 ミリ秒遅れます（オフにしても同じです）。


----------------------------------------------------------------------
■ トラブルシューティング
----------------------------------------------------------------------

・フィルタの一覧に「VAO Voice」が出ない
   OBS を完全に終了してから、もう一度起動してください。
   それでも出ないときは、インストーラーで入れ直してください。
   インストーラーと zip の両方で入れていると、VAO が 2 つ見つかって動かなくなります。
   どちらか一方だけにしてください。

・「あと 3 秒」のまま、測定が進まない
   次を確認してください。
   ・フィルタ名の左の「目」のアイコンが、オンになっているか。
     オフのときは、「このフィルターがオフになっています」と表示されます。
   ・マイクが、ミュートや無効になっていないか。
     音が届かないときは、「マイクの音が届いていません」と表示されます。
   ・OBS の音量メーターが、話したときに動いているか。

・「声が小さすぎて測れませんでした」と出る
   マイクの接続と、OBS のマイクが正しいものになっているかを確認してください。
   Windows のマイクの音量が極端に小さいときも、この表示になります。
   測定中の ④ で、普段の声で読んでいるかも確認してください。

・「入力が音割れしています」と出る
   マイク側の音量が大きすぎます。Windows のサウンド設定（マイクのプロパティ）や、
   オーディオインターフェースの音量を下げてから、もう一度「すべて自動設定」を押してください。
   ※ すでに割れている音は、VAO では直せません。

・「キーボードやマウスの音が大きく、声と近いため、完全には消せません」と出る
   マイクを口に近づけるか、キーボードやマウスからマイクを離してください。
   ほかには、ショックマウントや、マイクアームの利用も効果があります。

・声の出だしや語尾が切れる
   「ノイズゲート」のしきい値を、少し下げてください（左へ動かす）。
   それでも切れるときは、ノイズゲートのチェックを外してください。

・雑音が残る・小さく聞こえる
   「AI ノイズ抑制」の強さを上げ、「ノイズゲート」のしきい値を少し上げてください。
   それでも気になるときは、雑音の音源（ファンなど）を、マイクから離してください。

・しゃべりながら打つキーボードの音は消えない
   VAO のノイズゲートは、声がないあいだに音を静かにします。
   しゃべりながら打つ音は、声と同時に鳴るため、完全には消せません。
   マイクとキーボードの距離を離すのが、いちばん効果があります。

・AI ノイズ抑制が効かない
   OBS の音声設定のサンプルレートが、48 kHz か確認してください
   （OBS の「設定」→「音声」→「サンプルレート」）。48 kHz 以外では、この機能は動きません。
   OBS 標準の「ノイズ抑制」フィルタを、いっしょに付けている場合は、二重にかかるので、
   どちらか一方にしてください。

・声が不自然・こもる・金属的に聞こえる
   「AI ノイズ抑制」の強さを下げてください。
   EQ の「味付け」が強すぎる場合は、「ナチュラル」に戻して、もう一度「すべて自動設定」を押してください。

・「声がとても小さいです」と出る
   声の平均が、-40 dB より小さい状態です。VAO のゲインで持ち上げられますが、
   先に Windows の「サウンド」→「録音」→マイクのプロパティで、マイクの音量を上げるか、
   オーディオインターフェースのゲインを上げてください。雑音の割合が良くなり、さらに聞きやすくなります。
   （音割れしない範囲で上げてください）

・音量が大きすぎる・小さすぎる
   「出力ゲイン」のスライダーで調整してください。
   リミッターが働いているので、大きくしすぎても音は割れませんが、音がつぶれたように聞こえます。
   その場合は、ゲインを少し下げてください。

・音が少し遅れる
   VAO は、合計で約 12 ミリ秒遅れます（AI ノイズ抑制 約 10、リミッター 約 2）。
   通常の配信では気になりませんが、映像との同期を厳密に合わせたいときは、
   OBS の「音声の同期オフセット」で、ごく小さく調整できます。

・インストーラーで「WindowsによってPCが保護されました」と出る
   ソフトに電子署名が付いていないためです。「詳細情報」→「実行」を押してください。

・OBS にエラーが出る・OBS が起動しない
   一度 VAO を削除（アンインストール）して、OBS が起動するか確認してください。
   OBS のログ（「ヘルプ」→「ログファイル」→「現在のログを表示」）の、
   「[VAO]」と書かれた行を、連絡のときに教えてください。

■ バージョン履歴
----------------------------------------------------------------------

・v0.4.0 (2026-10)
  - 「目標の音量」のスライダーを追加しました（-18 LUFS 雑談配信向け 〜 -14 LUFS ゲーム配信向け、1 dB 刻み）。
  - 自動設定のあとでも、スライダーを動かすと、出力ゲインが自動で合わせ直されます。

・v0.3.0 (2026-10)
  - 「入力ゲイン」を、処理の先頭に追加しました。声が小さい人でも、AI ノイズ抑制などが正しく動きます。
  - 声がとても小さいときは、「マイク側の音量を先に上げてください」と案内します。
  - インストーラーの操作を減らしました。最初の画面で「インストール」を押し、最後に「完了」を押すだけです。
    （言語の選択画面と、準備完了の画面は出なくなりました）

・v0.2.0 (2026-10)
  - 初回公開版。
  - ハイパス・AI ノイズ抑制（RNNoise 内蔵）・ノイズゲート・EQ（味付け 6 種）・ディエッサーを追加。
  - 測定に、キーボードを叩く時間とマウスをクリックする時間を追加（合計約 26 秒）。
  - 日本語のインストーラー（exe）を追加。管理者権限は不要です。
  - コンプレッサーを強めに調整（声のばらつきをそろえて、音量を上げやすくしました）。

・v0.1.0 (試作・配布なし)
  - コンプレッサー・出力ゲイン・リミッターと、測定・自動設定を追加。

・v0.0.0 (試作・配布なし)
  - 音をそのまま通すフィルタ「VAO Voice」を作成。
